# DAFTAR | دفتر — بداية مشروع Flutter

هذه نسخة تأسيسية أولى لمشروع Android، مبنية على نموذج DAFTAR السابق.

## ما الموجود الآن؟
- واجهة عربية RTL.
- لوحة تحكم.
- أقسام العملاء والمنتجات والفواتير والمصاريف والمداخيل والديون والتقارير والإعدادات.
- إضافة وحذف سجلات عامة داخل كل قسم.
- تخزين محلي على الهاتف باستخدام SQLite.
- طباعة سجل الفاتورة إلى PDF.
- العمل الأساسي لا يحتاج اتصالاً بالإنترنت.

## ما لم يُنجز بعد؟
- تسجيل الدخول وحسابات المحلات.
- ربط Supabase والمزامنة السحابية.
- إدارة مخزون تفصيلية.
- فاتورة متعددة المنتجات والضرائب والخصومات.
- النسخ الاحتياطي والاسترجاع.
- اختبارات شاملة وتجهيز إصدار متجر Google Play.

لا تستخدم هذه النسخة بعدُ كسجل محاسبي رسمي أو لحفظ بيانات حساسة قبل إكمال النسخ الاحتياطي والأمان والاختبارات.

## فتح المشروع
1. أنشئ مشروع Flutter فارغاً باسم `daftar` أو استخدم مجلداً جديداً.
2. انسخ الملفات والمجلدات من هذه الحزمة إلى المشروع.
3. من الطرفية نفّذ:
   - `flutter pub get`
   - `flutter run`
4. لبناء ملف APK بعد تجهيز Android SDK:
   - `flutter build apk --release`

## ملاحظة مهمة للهاتف فقط
يمكن استخدام GitHub Codespaces من Chrome لكتابة الملفات وتشغيل أدوات التطوير السحابية، لكن إنشاء APK يحتاج بيئة Flutter وAndroid SDK. سنجهز ذلك خطوة بخطوة، ولا تشارك كلمات المرور أو مفاتيح Supabase السرية.
